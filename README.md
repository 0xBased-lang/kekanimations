# KEKTECH NFT Animation Project

This repository contains ComfyUI workflows and resources for creating animations from the KEKTECH NFT collection (4,200 unique Pepe NFTs).

## Project Goal

Create elegant, automated workflows in ComfyUI to:
- Generate animated versions of static NFT images
- Produce marketing content (GIFs, short videos)
- Enhance frontend with animated assets
- Maintain original character art style and quality

## Repository Structure

```
kekanimations/
├── workflows/          # ComfyUI workflow JSON files
├── research/          # Research documentation and findings
├── examples/          # Example outputs and samples
├── scripts/           # Automation scripts for batch processing
└── docs/              # Additional documentation
```

## Technologies

- **ComfyUI**: Node-based UI for Stable Diffusion workflows
- **AnimateDiff**: Primary animation engine for motion generation
- **ControlNet**: Preserve original character appearance
- **Batch Processing**: Automated workflow for collection-scale animation
